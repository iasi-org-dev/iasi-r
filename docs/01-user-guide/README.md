# IASI Quarto · User Guide

Fuentes de la **Guía de usuario** de `iasi.quarto`.

Esta edición describe el comportamiento actual de `iasi.quarto` 0.10.2:
tipos de proyecto, cuatro estrategias de libro, perfiles de salida y el ciclo
`validate → build → publish → release`.

La guía está escrita para usuarios. Los detalles de arquitectura e implementación
pertenecen a `02-developer-guide` y `03-technical-guide`.
